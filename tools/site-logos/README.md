# site logos

single color marks of popular sites from simple-icons 13.21.0 (CC0, https://github.com/simple-icons/simple-icons). the marks belong to their owners
and appear only to name the site on its tile. `tools/make_site_logos.py` draws them in the color of the brand as 128 pixel pictures
`app/icons/ui/yz-logo-<file>.png`, and `YZFavicons` shows them in place of a fetched favicon for the hosts it lists.
